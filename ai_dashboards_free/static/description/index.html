Ask for a dashboard. Get a real one.

Describe what you want in plain English to Claude, ChatGPT or Cursor. It lands in Odoo as a screen you open like any other — live, permission-aware, and never a screenshot.

The AI never writes code

It writes a specification — which model, which filter, which grouping, which measures — and Odoo validates it and draws the charts. There is no generated SQL anywhere in this module, and that matters more than it sounds: SQL written by a language model runs outside the ORM, and therefore outside every access right and record rule your database has. A specification cannot, because it is data rather than instructions.

Dashboards store the question, not the answer

A saved dashboard holds "revenue by month, this year" — never the numbers. The query runs when you open it, as you, through the ORM. So it is never stale, and it respects multi-company boundaries without anyone configuring anything.

What you get

Preview before it is saved Nothing is kept until you have looked at it. Drill through Click a bar, get the records behind it in a normal Odoo list.
Edit by conversation Ask for a change; the assistant reads what exists and proposes a diff instead of rebuilding. A light editor Drag to reorder, resize, rename, recolour — without going back to the chat.
Every version kept One-click revert when a change was wrong. Compare and pivot Last year or the previous period, across the whole dashboard; two-dimensional pivots with both axes paged.
